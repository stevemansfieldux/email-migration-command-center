Sign in with your local Claude

This app holds no key. It uses whatever credential the Anthropic SDK resolves on this machine, and the intended way to provide one locally is an OAuth profile from the Anthropic CLI:

brew install anthropics/tap/ant
xattr -d com.apple.quarantine "$(brew --prefix)/bin/ant"
ant auth login

That opens a browser, stores a profile under ~/.config/anthropic/, and this app picks it up on the next request — nothing to paste here. ant auth status shows which org and workspace the profile is bound to.

Two things worth knowing: a set ANTHROPIC_API_KEY silently wins over any profile, so leave it unset if you mean to use the profile. And Claude Code may warn about an auth conflict with its own login — keep one.
